# Installation

1. Fermer complètement Form@Prospect.
2. Copier le dossier `Form@Prospect` de l'archive dans `FormProspect_V1.1-D_TEST`.
3. Accepter le remplacement des fichiers.
4. Relancer avec le compte Administrateur.
5. Ouvrir **Formateurs**, ajouter au moins un formateur actif, puis tester la page Documents.

Aucun déploiement Render n'est requis pour ce lot Desktop.
