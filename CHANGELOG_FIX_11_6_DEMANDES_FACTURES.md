# Correctif Desktop 11.6 — Demandes de devis et factures

La rubrique « Devis & factures » permet maintenant au commercial de demander :

- un devis ;
- une facture.

## Interface

- L'onglet devient « Demandes de documents ».
- Le formulaire comporte un choix « Devis / Facture ».
- La liste affiche une colonne Type.
- Un filtre permet d'afficher uniquement les devis ou les factures.
- L'administrateur dépose automatiquement le bon type de document.
- Le commercial télécharge le document lorsqu'il devient disponible.
