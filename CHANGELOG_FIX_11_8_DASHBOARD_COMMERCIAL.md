# Correctif Desktop 11.8 — Dashboard commercial

- Le titre du Dashboard utilise désormais le prénom du compte connecté :
  « Bonjour Nacim 👋 », « Bonjour Nass 👋 », etc.
- Le nom du projet n'est plus utilisé comme nom dans le message d'accueil.
- Pour un compte Commercial :
  - « Nouveau projet » est grisé et désactivé ;
  - « Ouvrir » est grisé et désactivé ;
  - « Déployer » est grisé et désactivé.
- « Sauvegarder » et « Rafraîchir » ne sont pas modifiés.
- Les comptes non commerciaux conservent le fonctionnement actuel.
