# Correctif Desktop 11.3 — Formulaire de finalisation client

## Nouveau fonctionnement

- Le bouton redondant « Transformer en client » est supprimé.
- Le passage du pipeline vers « 🟢 Client » ouvre le formulaire complet.
- Le pipeline n'est modifié qu'après validation du formulaire.
- L'annulation conserve l'ancien statut du prospect.
- Un double-clic sur un client ouvre le même formulaire en modification.
- La génération de documents ne propose que les clients finalisés.
- Le formulaire collecte les informations juridiques et le représentant légal nécessaires aux conventions.
