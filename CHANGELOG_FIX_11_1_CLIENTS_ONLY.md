# Correctif Desktop 11.1 — Clients uniquement

- La liste Nouvelle vente affiche uniquement les fiches CRM au statut `🟢 Client`.
- Le libellé `Client / prospect` devient `Client`.
- Le message vide invite à transformer d'abord un prospect en client.
- Le bouton `Transformer en client` fonctionne maintenant en mode Cloud.
- Après transformation, le client devient disponible dans Ventes & commissions.
- L'export CRM reste masqué et interdit pour les commerciaux.
