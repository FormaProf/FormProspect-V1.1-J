# Correctif Desktop 11.5 — Demandes de devis

La rubrique Devis & factures comporte maintenant deux onglets :

1. Devis & factures
2. Demandes de devis

Commercial :
- bouton « Demander un devis » ;
- choix du client finalisé et de la formation ;
- note facultative à l'administrateur ;
- suivi du statut ;
- téléchargement du devis lorsqu'il est disponible ;
- annulation possible tant que la demande est à traiter.

Administrateur :
- vue de toutes les demandes ;
- passage en préparation ;
- dépôt du devis ;
- association automatique du devis à la demande ;
- refus d'une demande.
