# Installation — Correctif catalogue des formations

## 1. Backend Cloud
Copier le contenu du dossier `backend` dans la racine du dépôt `formaprospect-cloud-local`, tester, committer et pousser sur `main`.

Aucune migration Alembic n'est nécessaire.

## 2. Application Windows
Après le déploiement Render réussi, fermer Form@Prospect puis copier le dossier `Form@Prospect` dans le dossier principal `FormProspect_V1.1-D_TEST` en acceptant le remplacement des trois fichiers.
