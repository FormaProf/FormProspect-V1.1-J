# Notes de version — Form@Prospect 1.0.0

Date de préparation : 13 juillet 2026

## Première version officielle

Form@Prospect 1.0.0 fournit un environnement Windows complet pour importer, organiser et suivre une base de prospects B2B.

## Points forts

- projets indépendants et données stockées localement ;
- CRM en vue Tableau ou Kanban ;
- recherche, filtres, tri et pagination ;
- glisser-déposer du pipeline ;
- notes et historique des actions ;
- dashboard commercial ;
- export Excel ;
- sauvegarde et restauration sécurisées ;
- installateur Windows avec identité Form@Prospect.

## Formats pris en charge

- import : Excel `.xlsx` ;
- export : Excel `.xlsx` ;
- sauvegarde : `.fpbackup`.

## Périmètre de la version 1.0

Les espaces Dashboard, Traitement et CRM constituent le périmètre fonctionnel validé. Les fonctions cloud, multi-utilisateur, emailing, intelligence artificielle, licences en ligne et import CSV direct ne font pas partie de cette version.

## Données

Les projets et leurs bases restent stockés localement. Il appartient à l’utilisateur d’organiser des sauvegardes régulières et de les conserver sur un support distinct.

## Mise à jour

Avant toute future mise à jour :

1. ouvrir le projet actuel ;
2. créer une sauvegarde `.fpbackup` ;
3. fermer Form@Prospect ;
4. installer la nouvelle version ;
5. vérifier l’ouverture du projet et les données principales.
