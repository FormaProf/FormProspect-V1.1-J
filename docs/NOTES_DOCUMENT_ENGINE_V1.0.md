# Form@Prospect V1.0 — Document Engine

## Nouveautés

- Fusion OOXML directement dans les modèles Word officiels.
- Conservation de la mise en page, des images, tableaux, styles, en-têtes, pieds de page et sauts de page.
- Installation automatique des modèles Form@Prof officiels.
- Convention, Programme et Convocation disponibles depuis l'assistant de génération.
- Le devis n'est plus proposé dans l'assistant : il reste produit par la plateforme externe puis importé dans le dossier formation.
- Blocage de la génération lorsqu'un modèle officiel est absent ou invalide.
- Dates françaises et variables métier enrichies.

## Compatibilité

Les anciens dossiers et bases SQLite sont conservés. Les chemins des modèles sont recalculés automatiquement lorsque l'application est déplacée.
