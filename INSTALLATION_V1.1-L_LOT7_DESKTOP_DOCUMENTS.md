# Installation — Lot 7 Documents Cloud Desktop

Copier le dossier `Form@Prospect` de l'archive dans le dossier principal de l'application Windows :

`C:\Users\Nacim\Desktop\MAJ Form@Prospect\FormProspect_V1.1-D_TEST\Form@Prospect`

Accepter le remplacement des trois fichiers suivants :

- `services\cloud_api_client.py`
- `ui\pages\documents_page.py`
- `ui\dialogs\generate_documents_dialog.py`

Ne rien copier dans `formaprospect-cloud-local` et ne pas lancer de déploiement Render pour ce lot.

Fermer complètement Form@Prospect avant la copie, puis relancer l'application.
